\chapter[Recommendations and Next Steps]{Recommendations \& Next Steps}
\label{cp:Recommendations-and-Next-Steps}

{
  \parindent0pt
  To build on the current prototype, we have a clear roadmap for future development.

  \begin{description}
    \item[Immediate Next Steps (3--6 Months):]

          \begin{itemize}
            \item \textbf{Develop Custom Dataset:} Launch a data collection campaign for at least 5,000 annotated images of local waste. This is our highest priority for improving model accuracy.

            \item \textbf{Fine-Tune Model:} Use the new dataset to fine-tune the Gemini Vision model.

            \item \textbf{Launch Pilot Program:} Roll out the Ayang web app to 3--5 pilot communities to gather user feedback and test assumptions.

            \item \textbf{Establish Partnership:} Initiate a formal partnership with a local municipal waste authority or recycling company to solve the "last mile" disposal problem.
          \end{itemize}

    \item[Medium-Term Goals (6--18 Months):]

          \begin{itemize}
            \item \textbf{Full Public Launch:} Launch Ayang to the general public in a target city, accompanied by a marketing campaign.

            \item \textbf{Advanced Gamification:} Introduce features like team vs. team challenges, special achievement badges, and corporate-sponsored prizes to provide a potential revenue stream.

            \item \textbf{Data Dashboard for Authorities:} Develop a web-based dashboard for municipal partners with real-time data visualizations and analytics.
          \end{itemize}

    \item[Long-Term Vision (2+ Years):]

          \begin{itemize}
            \item \textbf{National and Regional Scaling:} Expand the platform to other cities and countries, adapting the AI model for each new locality.

            \item \textbf{Integration with Circular Economy:} Forge partnerships with manufacturers and recycling plants to create a closed-loop system, using Ayang's data to predict the supply of recyclable materials.

            \item \textbf{Policy Advocacy:} Use the accumulated data to advocate for better waste management policies, such as extended producer responsibility (EPR) laws.
          \end{itemize}
  \end{description}

  
}
